# 定义与问题

## 定义
深度学习  
- 是机器学习的一个分支  
- 它使用 **多层神经网络**，从 **原始数据** 中 **自动学习特征**， 并完成预测或决策

## 问题
1. 什么是“多层神经网络”  
2. 什么是“自动学习特征”  
3. 为什么强调“原始数据”  

# 应用领域
商品推荐、文本翻译、人脸识别、自动驾驶  

深度学习根据任务类型和数据形态分为：  
1. 计算机视觉 (CV)  
  这是深度学习最早爆发的领域。  
  图像分类，目标检测，图像分割，人脸识别，  
  手机里的"拍照识花"，工厂质量检测，医院 CT 影像辅助诊断，背后都是计算机视觉。
  这些任务在深度学习出现之前都是极其困难的，而现在已经是工业级成熟技术。  
2. 自然语言处理 (NLP)  
  文本分类，机器翻译，问答系统，文章摘要，情感分析。  
  ChatGPT 的底层就是 NLP 领域的深度学习模型。
  大语言模型（LLM）的出现，让 NLP 进入新纪元。  
3. 智能语音  
  语音识别（语音转成文字），语音合成（文字转成语音），声纹识别（声音辨别身份）。  
  支撑手机助手，智能音箱，电话客服机器人。  
4. 推荐系统  
  短视频推荐，电商商品推荐，个性化广告，  
  背后都是深度学习驱动的推荐模型。  
5. 时间序列  
  销售额预测、股价预测、设备异常检测、电网负荷预测。  
  适用对时间有关的序列数据进行预测。  

# 传统机器学习的局限

![](../materials/img0001MLprocess.png)

传统机器学习流程中的特征工程尤为重要  
虽然有 `fg-data-profiling, sweetviz` 等 EDA 工具辅助，但是依赖人工经验  
而且不能直接处理非结构化数据。  

**特征提取**  
是将人类的领域知识转为模型可理解的数学特征的过程  

传统特征提取的核心瓶颈  
1. 严重依赖领域专家  
  图像特征需要图像处理专家，语音特征需要信号处理专家，文本特征需要语言学专家。  
  更换领域需要重新设计特征，成本极高而且难以复用。  
2. 无法处理复杂数据  
  难以通过手工特征描述高层次的语义概念  
  例如语言中的语气，以及图片中的气氛  
3. 制约模型性能表现  
  模型表现的上限受到人工特征的质量制约  

# 深度学习的思路转变
既然人类难以完成特征定义，机器何不自己通过数据总结？

**深度学习核心创新**  
- 将 **特征提取** 也纳入学习过程
- 和传统机器学习的本质区别

## 示例2 CNN 猫识别

![](../materials/img0003CNNcat.png)

**从像素到概念逐层抽象**  
CNN 会重复卷积、激活、池化直到展平的过程

1. 第一层  
  不识猫为何物，识别基础元素  
    - 横线
    - 竖线
    - 斜线
    - 颜色边缘
2. 中间层  
  组合基础元素，识别复杂结构  
     - 弧线
     - 纹理
     - 局部形状

     - 耳朵三角形
     - 胡须细线条
4. 最终层  
  综合所有特征，输出预测概率  
     - 97% 是猫

# 深度学习的发展简史

## 三起二落
实际上，深度学习最初的名字叫神经网络，早在 1950 年代就与机器学习并行发展。  
它的灵感源于仿生学——模拟动物神经元的思考与推理方式。

### 一次兴起
1. **思想起点**  
1943年，神经科学家 麦卡洛克 (McCulloch) 和数学家 皮茨 (Pitts)  
提出第一个数学神经元模型，用数学方式模拟人类神经元的工作原理
2. **首次春天**  
1958年，心理学家 罗森布拉特 (Rosenblatt)  
在前者基础上提出 **感知机** (Preceptron)，这是神经网络最早的可运行模型，能学习简单线性分类规则  

### 一次衰落
**首次寒冬**  
1969年，AI 先驱 明斯基 (Minsky) 和 帕珀特 (Papert)  
在 《感知机》 (Preceptrons) 一书，用严格的数学证明感知机无法解决 异或 (XOR) 等非线性问题。该批评指出感知机的致命弱点。

### 二次兴起
**二次春天**
1986年，鲁梅尔哈特 (David Everett Rumelhart) 和 辛顿 (Geoffrey Hinton) 等人  
系统阐述 **反向传播算法** (Back propagation)，解决多层神经网络高效训练的核心问题  

### 二次衰落
**二次低谷**
1990年代，支持向量机 (SVM) 在多数任务上表现优于神经网络，理论清晰而且训练稳定  
同时神经网络面临数据和算力的匮乏，以及梯度消失等技术难题，再次陷入低谷

### 三次兴起
**技术元年**
2006年，辛顿 (Geoffrey Hinton) 和学生  
发表 深度信念网络 (Deep Belief Network) 和 逐层预训练方法，成功训练更深的神经网络。  
论文首次使用 **深度学习** (Deep Learning) 一词，称当时为深度学习元年  
后2024年辛顿因此获得诺贝尔物理学奖  

## AlxeNet 引爆
2012年 ImageNet 大规模视觉识别挑战赛，亚历克斯·克里热夫斯基 (Alex Krizhevsky)  
通过 AlexNet 的深度卷积神经网络，实现 15.3% 的错误率夺冠  

深度学习三大爆发条件：
1. 互联网大数据  
互联网的普及奠定获取大规模数据的基础  
李飞飞主导的 ImageNet 拥有 1400 万标注图像数据集  
2. GPU 硬件发展  
GPU 的并行算力极大提高大规模矩阵运算速度，缩短训练时间  
伊利亚·苏茨克弗 (Ilya Sutskever) 敏锐意识到 GPU 并行运算能力的应用  
3. 训练技巧积累  
ReLU 激活函数，Dropout 正则化，更佳的初始化策略  
长期的工程积累共同降低深层网络的训练难度  

## Transformer 一统
2017年，Google 团队发表论文 Attention Is All You Need，提出 Transformer 架构  
凭借强大的泛化能力迅速统一 NLP, CV, 语音等多模态领域，成为如今大模型的基础  
催生后续 BERT, GPT 系列 LLM  
Transformer 集成 Attention, Residual Connection, Layer Norm 等成熟的深度学习组件  

## 生成式AI 元启
2022年， OpenAI 发布 ChatGPT  
它不是首个语言模型，也不是技术上最领先的模型  
但它首次让普通用户感受 AI 对话的惊艳表现  
自此深度学习从实验室进入日常应用，生成式 AI 新纪元开启
